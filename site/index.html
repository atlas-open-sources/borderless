Before you
say hello.

Do I need glasses?

No. Borderless works as a standalone phone experience. Glasses provide optional views of the same conversation.

Does the demo use my microphone?

No. The browser demo is scripted. The spoken recording uses generated voices processed through Meta transcription and translation. Playback makes no new model calls and never uses your microphone.

Where does live speech go?

This prototype uses remote Meta speech and language services through a private relay. Live audio and text leave the phone. API credentials stay in the relay, not in the app. This version is not fully local.

What’s working today?

The native simulator experience, translation pipeline and host-only replies are tested. Generated audio has passed real Meta speech-to-translation checks, including a round trip from the Swift client. Physical pairing, optical output, microphone routing and band input still need attended validation.

Can I download it?

Not publicly yet. Borderless is a working prototype being prepared for hardware testing. Try the simulated experience now; a public app release will follow separate validation and distribution.
