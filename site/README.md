# Borderless website

Local preview: `python3 site/serve.py`, then http://127.0.0.1:8769/.

Paper/ink and heavy Roboto follow Atlas Codes. The animated globe reuses Atlas's pinned Natural Earth coastline dataset, without political borders or ASCII land fill. Blue/green remain reserved for host/guest.

Includes responsive desktop/mobile layout, explicit reduced-motion handling, pauseable/offscreen-paused globe, static SVG fallback, semantic navigation, keyboard focus, interactive private-reply example, native simulator recording and factual prototype/privacy FAQ. No analytics, microphone access, cookies or provider calls. All website assets served locally.
